# Glosario de términos frecuentes

| Término técnico | Lenguaje simple |
|---|---|
| Esteatosis hepática | Acumulación de grasa en el hígado ("hígado graso") |
| Litiasis vesicular | Piedras en la vesícula |
| Nódulo | Una pequeña zona de tejido distinta a su alrededor; no significa necesariamente algo grave |
| Benigno | No es cáncer |
| Maligno | Es cáncer |
| Adenopatía | Ganglio linfático aumentado de tamaño |
| Derrame pleural | Líquido acumulado alrededor del pulmón |
| Atelectasia | Una parte del pulmón que no se está llenando bien de aire |
| Hemoglobina glicosilada (HbA1c) | Examen que muestra el promedio de azúcar en la sangre de los últimos 3 meses |
| Creatinina | Examen que muestra qué tan bien funcionan los riñones |
| Hipodenso / hipoecogénico | Se ve más oscuro en la imagen que el tejido de alrededor |
| Sin hallazgos patológicos | No se encontró nada anormal |
| Control en X meses | Se recomienda repetir el examen en ese plazo |
