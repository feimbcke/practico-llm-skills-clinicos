# Referencia resumida BI-RADS (mamografía)

## Densidad mamaria
| Código | Descripción |
|---|---|
| a | Mamas casi completamente adiposas |
| b | Áreas dispersas de densidad fibroglandular |
| c | Heterogéneamente densas, pueden ocultar lesiones pequeñas |
| d | Extremadamente densas, disminuye la sensibilidad |

## Categorías de evaluación
| Categoría | Significado | Conducta habitual |
|---|---|---|
| 0 | Incompleto, requiere estudio adicional | Imágenes complementarias |
| 1 | Negativo | Control rutinario |
| 2 | Hallazgo benigno | Control rutinario |
| 3 | Probablemente benigno | Control a corto plazo |
| 4A / 4B / 4C | Sospecha baja / moderada / alta de malignidad | Biopsia |
| 5 | Altamente sugerente de malignidad | Biopsia |
| 6 | Malignidad confirmada por biopsia | Manejo oncológico |

Fuente: resumen docente basado en ACR BI-RADS Atlas, 5.ª edición. Usar solo con fines educativos.
